# mrc-dissipation (Monitored random circuits with dissiaption)
This contains all the codes that generate figures for the publication: PRB 108, 104310 (2023), where we study the measurement induced phase transition in the presence of dissipation. The transition is destroyed in finite systems but needs more examination in the infinite system size limit. 

The circuit evolution is implemented using sparse matrix multiplication and is not optimized for performance.

To see more optimized excution using tensordot, refer to the repo later projects on two-stage decay and Liouvillian gap.
